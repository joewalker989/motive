Use a Scriptable widget to put the quote itself on your iPhone’s Home Screen.

  1. Install Scriptable from the App Store.
  2. Open Scriptable, tap ＋, and name the script Motive.
  3. Use the button below to copy the code. Paste it into Scriptable, then tap ▶ while online.
  4. Hold an empty spot on your Home Screen. Tap Edit → Add Widget → Scriptable.
  5. Choose a medium widget. Hold it, tap Edit Widget, then select the Motive script.
  6. In that same Edit Widget screen, set Parameter to All,photo,60 for the settings below. Old parameters such as All,sage,60 keep photos off even after replacing the code.
