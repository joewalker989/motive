Your daily quote, at a glance.

Use a Scriptable widget to put the quote itself on your iPhone’s Home Screen.

  1. Install Scriptable from the App Store.
  2. Open Scriptable, tap ＋, and name the script Motive.
  3. Use the button below to copy the code. Paste it into Scriptable, then tap ▶ while online.
  4. Hold an empty spot on your Home Screen. Tap Edit → Add Widget → Scriptable.
  5. Choose a medium widget. Hold it, tap Edit Widget, then select the Motive script.
  6. In that same Edit Widget screen, set Parameter to All,photo,60 for hourly photo quotes. Old parameters such as All,sage,60 keep photos off even after replacing the code.

Go to website ↗

The widget checks for new published quotes daily and avoids repeats. In medium and large widgets, tap Go to website to open Motive; tapping the quote opens Scriptable with a new quote preview. A small widget opens the website from any tap. It does not refresh in place on the Home Screen. The Home Screen catches up when iOS refreshes. iOS can delay your chosen refresh interval, and there is no reliable refresh-on-unlock trigger. Personal quotes stay in the website. Website updates do not replace the script saved on your phone. Replace all the old Motive code with the copied code, run it online, and check that the preview says MOTIVE v6 and shows a photo. If it says PHOTO UNAVAILABLE, reconnect and run again.
