# The 20-feature update

The website remains free. “Native source” means implemented in the Xcode project, not installed or activated on an iPhone/Watch. The user's regular Apple account and Windows computer do not provide a signed native installation.

| Requested feature | Delivered status |
| --- | --- |
| 1. Read aloud | Device speech on the quote card and in Listen. |
| 2. Personal photo backgrounds | Studio > Settings; local photo processing and image downloads. |
| 3. Scheduled reminders | Free daily calendar export and while-open browser alerts. Closed-app local quote notifications implemented in native source. |
| 4. Font/layout customization | Font/alignment preview and download font, size, alignment, and text color. |
| 5. Guided programs | Three original seven-step Confidence, Focus, and Calm journeys. |
| 6. Lock Screen quotes | Rectangular and inline WidgetKit families added to native source. Existing Scriptable Home Screen widget is retained. |
| 7. Personal voice recordings | Explicit microphone recording, one-minute cap, local storage. |
| 8. Ambient audio | Synthesized rain noise and warm tones during timed sessions. |
| 9. Audio playlists | Saved quotes, quote themes, or personal voice recordings; stop control and adjustable speech speed. |
| 10. Morning/evening routines | Separate moment selection and daily rotating prompts. |
| 11. Guided journal prompts | Fourteen original prompts rotating across the week. |
| 12. Mood trends | Last seven recorded daily check-ins, displayed by date without a score. |
| 13. Vision board | Local photos and meaningful goal captions. |
| 14. Photo journal | Optional resized photo attached to each journal entry. |
| 15. Voice journal | Optional voice reflection attached to a written/photo journal entry. |
| 16. Device sync | Optional encrypted WebDAV adapter, conditional writes and merge tests. Requires a user-controlled server; no service connected. |
| 17. Journal lock | AES-GCM browser journal vault. Native journal adds Face ID/device passcode and complete file protection. |
| 18. Apple Watch | Standalone Watch quote-reader source with its own non-repeating reading history. Requires signed installation and device testing. |
| 19. Multiple languages | Partial: English/Spanish/French studio navigation and 15 affirmation cards. Main quote library, prompts, detailed settings, and session guidance remain English. |
| 20. Siri | Native App Shortcuts for reading a quote and opening a calming session, compatible with iOS 17. Requires installed native app. |

The additional meditation request is delivered through five web session modes and a native timer. Web modes include gentle paced breathing, even breathing, grounding, body awareness, and a silent timer, with 1–20 minute choices, pause/resume, natural breathing, optional guidance speech, reduced motion, and background audio.

See [Wellbeing.md](Wellbeing.md) for storage, backup, encryption, reminder and sync details. Actual iPhone/Watch behavior still requires on-device testing. Microphone permission, installed speech voices, and audio format playback depend on the browser/device.
